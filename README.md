# ノリダン

ノリで断れない、身内ノリの飲み会ゲーム。Expo（React Native）製で、iPhone / Android / Web を同じコードで出せる。

## 第1弾の中身

- **アホお題**：順番に理不尽なお題。たまに【緊急】割り込み指令（数ターン続くルールあり）
- **すごろく**：30マスのヘビ型の道。マスは色とアイコン（+2・−3・休・⇄・！）、サイコロはタップで振ってコマが1マスずつ進む。止まったらお題札がせり上がる
- **メンバー登録**：呼び名＋イジりネタ。ネタはお題に勝手に混ざる
- **地獄度**：ゆるめ／普通／地獄（画面の色も変わる）
- **本日の戦犯**：罰が一番多かった人を発表
- **セーフ／アウト**：1人用のお題は2択ボタンか札のスワイプ（右＝セーフ、左＝アウトで罰）。逃げた・できんかった・判定負けは全部アウト。他の人に罰をつけたい時だけ「他の人に罰をつける」で一覧を開く。全員参加や「負けた方が罰」みたいな勝負のお題は一覧から選ぶ。一覧の見出しはお題に合わせて変わる（例：「一番遅い奴が罰」→「一番遅い人は？」。判定は `src/lib/game.ts` の `penHead`）
- **分かりやすさ**：倍プッシュ・時限爆弾・緊急指令・リベンジ権などが初めて出た時だけ、札の下にひとこと説明（1回見たら出えへん）。札に「ひとり／勝負／全員／ルール」のタグ。⋯メニューにルール早見表。結果発表に罰の内訳（アウト・違反・倍プッシュ失敗…）。勝負のお題は負けた人を選ぶまで次へ進めへん
- **ルール違反**：「発動中」の枠の「違反者に罰」から、お題の途中でもいつでも破った人に罰ガチャ
- **罰ガチャ**：罰がついたら中身がランダムで決まる。ドクロが出たら罰、たまに天使が出たらラッキーで帳消し
- **当てはまらん → 誰かに回す**：お題が自分に当てはまらん時（元恋人おらん等）、ランダムで別の人に回せる。1枚1回、罰なし
- **リベンジ権**：罰を受けた人がもらえる。自分のお題を誰かに押し付けられる（1回きり）
- **ダブルアップ**：たまに来る。お題を見る前に倍プッシュ → 成功で誰かに罰、失敗で罰2倍
- **全員参加お題**：多数決・せーので系が混ざる
- **時限爆弾**：仕掛け人だけがNG行動を知る。数ターン後に爆発して、やった奴が全員罰
- **夜モード（隠し）**：ホームのロゴを素早く3回タップ → 全員OKで発動。夜モード中にもう一回3回タップで深夜の確認画面。「夜」（普通のお題にたまに混ざる）と「深夜」（お題が全部下ネタ）の2段階。メンバーごとに下ネタNG、夜お題は罰なしパス可
- **向かい合わせ表示**：設定でON。お題が上下2面に出て、机の真ん中に置いたら両側から読める
- **読み上げ**：設定でON。札が出たら端末の日本語音声で読む（expo-speech）。時限爆弾の中身は読まへん
- **称号**：結果発表で「逃げ切り王」「天使に愛された人」「リベンジの鬼」「ギャンブラー」などをつける（判定は `src/lib/titles.ts`）。シェア画像にも載る
- **画面スリープ防止**：ゲーム中は画面が消えへん（expo-keep-awake）
- **夜モードのネオン看板**：夜お題・深夜お題が出たら照明が落ちて、札とボタンがネオン管みたいに光る。ホームのロゴもネオンでチカチカ
- **押した感触**：ボタンは押すと沈んでぷにっと戻る＋軽いバイブ（`src/components/Tap.tsx`）
- **振ってルーレット**：スマホを振ると次へ／サイコロ（ホームの設定でON/OFF。iPhoneのブラウザは初回に許可を聞かれる）

見た目まわり：

- お題は画面いっぱいの「札」がめくれて出る。画面のフチが番の人の色で光る
- ホームは「メンバー → モード選択」の2ステップ。右上の歯車で設定（振る・効果音・夜モード・遊び方）
- 罰ガチャはカプセル演出、時限爆弾は導火線と爆発フラッシュ、倍プッシュはコイン
- 上下反転ボタン（向かいの人に見せる用）、初回だけ遊び方ガイド
- ゲーム中の上には罰スコアの顔アイコン列、反転・結果・設定・やめるは右上の「⋯」メニュー
- お題の長さで文字サイズが自動で変わる。札の後ろに山札、次の番の人を予告
- メンバーは名前を打ってEnterで連続追加、名前タップでイジりネタ。遊んだメンバーは「前回のメンバー」から呼び出せる
- 結果は「画像で保存・シェア」でストーリー用の画像に（react-native-view-shot ＋ expo-sharing）
- 効果音は `assets/sounds/*.wav`（`python3 scripts/make_sounds.py` で作り直せる）

出る確率は `src/lib/game.ts` の `CHANCE` で調整できる。

## はじめかた

```bash
npm install
npx expo install --fix   # Expoのバージョンに合わせて依存を揃える
npm run web              # ブラウザで確認
npm start                # QRコードをiPhoneの「Expo Go」で読むと実機で動く
```

## Web版をVercelで公開（無料）

今は依存なしのWeb版（`web-preview/`）をそのまま公開する設定になってる（`vercel.json`）。npm installも要らんので、ビルドは数秒で終わる。

1. GitHubにリポジトリを作ってpush
2. Vercelで「Add New → Project」→ そのリポジトリを選ぶ
3. 設定は `vercel.json` に入ってるので、そのまま Deploy

- ビルド：`node web-preview/build.mjs --site` → `dist/` に index.html・アイコン・manifest が出る
- アイコンやシェア用画像は `web-preview/public/`
- スマホで開いて「ホーム画面に追加」するとアプリっぽく全画面で動く

Expo版のWebに切り替える時は、`vercel.json` を `{"buildCommand": "npx expo export --platform web", "outputDirectory": "dist"}` に戻す（`installCommand` の行は消す）。

## お題を増やす・直す

お題は全部で約470個（ゆるめ79・普通80・地獄80・全員参加50・夜60・深夜100・イジり22）、緊急指令31個。古今東西やしりとりみたいな「詰まる系」は、詰まるまで何周でも続けるルール。

ぜんぶ `src/data/` のJSON。コードは触らなくていい。

| ファイル | 中身 |
| --- | --- |
| `odai.json` | アホお題（`yurume` / `futsu` / `jigoku`）、全員参加（`minna`）、夜モード（`yoru`）、深夜モード（`shinya`）、イジりお題（`neta`） |
| `batsu.json` | 罰ガチャの中身（`bad`＝普通の罰、`yoru`＝夜モードの罰、`shinya`＝深夜モードの罰、`lucky`＝天使で帳消し）。夜は4割、深夜は6〜7割が夜系の罰になる（深夜×地獄はお題も罰も全部深夜系）。下ネタNGの人には普通の罰だけ |
| `bombs.json` | 時限爆弾のNG行動（「〜した奴」の「〜した」部分） |
| `events.json` | 緊急割り込み。`turns` が1以上だとそのターン数ルールが続く |
| `board.json` | すごろくのマス |

「少数派」「多数決」「指差せ」「被らんかった」みたいな3人以上おらんと成立せえへんお題は、2人の時は自動で出えへん（判定は `src/lib/game.ts` の `NEEDS_3`）。

お題の中で使える差し込み：

- `{P}` 今の番の人
- `{X}` ランダムな別の人
- `{Y}` さらに別の人（3人以上のときだけ出る）
- `{NETA}` `{X}` のイジりネタ

## フォルダ構成

```
App.tsx                 画面の切り替え・メンバー保存
src/screens/            ホーム / アホお題 / すごろく / 結果
src/components/Stage.tsx お題カード・罰チップなど共通パーツ
src/lib/game.ts         お題の差し込み・山札（同じお題が続かない）・確率
src/lib/useTurnFlow.ts  カード1枚の流れ（罰→罰ガチャ→時限爆弾、ダブルアップ、リベンジ）
src/lib/useShake.ts     振ったら次へ（アプリは加速度センサー、Webはdevicemotion）
src/lib/sound.ts        効果音（expo-audio）
src/components/Icon.tsx  線のアイコン（react-native-svg）
src/components/GameMenu.tsx ゲーム中の「⋯」メニュー
src/components/Board.tsx すごろく盤・コマ・サイコロ・進み具合バー
src/components/Fx.tsx   演出（カプセル・爆弾・コイン・導火線・フラッシュ）
src/components/SettingsSheet.tsx / Tutorial.tsx  設定シートと遊び方
src/data/               お題データ
web-preview/            依存なしで動くお試し版（script.js=ロジック / views.js=画面 → node web-preview/build.mjs）
```

## App Storeに出すとき（あとで）

- Apple Developer Program（年$99）に登録
- `npx eas build -p ios` → `npx eas submit -p ios`（Macなしでも可）
- プライバシーポリシーのURLが必要（データは端末内だけに保存、と書けばOK）
- 年齢区分は17+推奨。「飲酒を強要しない」作りはこのまま維持する
- 夜モードのお題は「トークだけ」。深夜モードはハグ・手つなぎ程度の軽いタッチあり（脱ぐ・露骨な性描写は入れない）。体に触るお題は審査で突っ込まれやすいので、深夜ごと `ALLOW_SHINYA` で外せるようにしてある
- 深夜モードで審査に引っかかったら、`src/lib/game.ts` の `ALLOW_SHINYA` を `false` にしてアプリ版だけ外す（Web版は残せる）
